# Functional Chord Notation

- Load FunctionalNotation.xml in chord symbols Style settings
- turn off case sensitivity
- Use C F G for T S D correspondingly.
- Use b for gleichnamig Moll and # for gleichnamig Dur, bb or ## for tritone
- use B for L and D for U
- use o for dim and 0 for semi-dim
- use 1 for typing modifiers (upper-index). In modifiers type refular notes instead of function aliases
- you can try notating bass with /, but It's not possible to place it correctly with complex chords
